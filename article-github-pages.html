GITHUB

GitHub Pages for beginners

GitHub Pages can publish static HTML, CSS, and JavaScript files from a repository. A user site can use a repository named username.github.io.

Basic setup

  1. Create a repository with the correct name.
  2. Add your index.html and other site files.
  3. Open the repository Settings and find Pages.
  4. Select the publishing source and wait for the deployment.

What it is good for

It is useful for blogs, portfolios, documentation, landing pages, and other static sites. It does not provide server-side PHP, Python, or Ruby execution.

Check GitHub's current terms and limits before using Pages for a commercial project.
